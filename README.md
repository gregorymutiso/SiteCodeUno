# WebDev Pro - Premium Website for Web Development Business

A high-converting, sales-focused website designed to attract small to medium-sized businesses looking for professional web development services.

## Features

- **Conversion-Focused Design**: Every element drives visitors toward contact and booking
- **Mobile-First Responsive**: Optimized for all devices
- **Fast Loading**: Optimized for performance
- **SEO-Friendly**: Proper structure and meta tags
- **Modern UI/UX**: Clean, premium design with smooth animations

## Pages

1. **Home** (`index.html`) - Landing page with hero, testimonials, value props, services preview, portfolio preview
2. **Services** (`services.html`) - Detailed service offerings with pricing
3. **Portfolio** (`portfolio.html`) - Showcase of successful projects
4. **About** (`about.html`) - Company story and credibility
5. **Contact** (`contact.html`) - Lead capture form and contact information

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- Google Fonts (Inter)

## Getting Started

1. Clone or download the files
2. Add your actual images to `assets/images/`
3. Update contact information in all HTML files
4. Customize content to match your brand
5. Deploy to your hosting provider

## Customization

- Colors: Primary blue (#007bff), dark text (#1a1a1a), gray text (#666)
- Typography: Inter font family
- Spacing: Consistent 2rem base padding
- CTAs: Blue primary buttons, white secondary buttons
